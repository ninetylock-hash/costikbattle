# COSTIK BATTLE 2.3 — Mixed Drop

## Что изменено
- В каждом из 20 кейсов формируется 36 разных позиций дропа.
- Для каждого предмета считается отдельная вероятность; шансы нормализуются до 100%.
- Предметы подобраны по диапазону от ~0.33x до 10x стоимости кейса.
- Есть два профиля вероятностей: STANDARD (математически рискованный) и HIGH RETURN (повышенный ожидаемый возврат). Фактический ROI зависит от актуальных рыночных котировок.
- Кастомные изображения кейсов созданы для COSTIK BATTLE и хранятся локально в `public/images/`.
- Скины получают изображения из публичного каталога ByMykel CSGO-API.
- Цены запрашиваются из публичного прайс-листа Market.CSGO `https://market.csgo.com/api/v2/prices/RUB.json`, кэшируются на сервере и обновляются каждые 5 минут.
- В интерфейсе цены показаны в TOKENS. В демонстрационной экономике 1 token = 1 RUB; это не реальные деньги, токены нельзя вывести или обменять.
- Если Market.CSGO недоступен, сайт явно показывает, что используются демонстрационные цены.

## Запуск
1. Установите Node.js 18 или новее.
2. Распакуйте архив.
3. В корне проекта выполните `npm install`.
4. Скопируйте `.env.example` в `.env` и укажите `STEAM_API_KEY`, `BASE_URL`, `SESSION_SECRET`.
5. Выполните `npm start`.
6. Откройте `http://localhost:3000`.

Steam login требует действующий Steam Web API key и публичный адрес сайта, настроенный в Steam OpenID.

## Цены и API
Market.CSGO предоставляет публичный список лучших предложений в RUB. Сервер читает его без приватного API-ключа. Цены конвертируются в целые виртуальные токены по правилу 1 RUB = 1 token. Доступность API и конкретных предметов зависит от Market.CSGO; в случае ошибки показывается демонстрационный набор, не выдаваемый за актуальные котировки.

## Важно
Это демонстрационный кейс-сайт с виртуальным балансом. В нём нет реальных денежных платежей, вывода средств или гарантии рыночной стоимости дропа. Вероятности и ожидаемый возврат рассчитываются на сервере.
